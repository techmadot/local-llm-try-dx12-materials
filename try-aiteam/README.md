## 本プロジェクトで作成するアプリケーション

このプロジェクトは DirectX12 (D3D12) のサンプルアプリケーションを作成します。
最小限の描画コード、ロギング、画面キャプチャを備えます。

### アプリケーションの基本仕様

アプリケーションの名前を、 `D3D12Triangle-Hello.exe` とします。

- Windows デスクトップアプリケーションで、描画解像度(クライアント領域)サイズを 1280x720 とする
- グラフィックスAPIとして、DirectX12 を使用する
- RGBそれぞれで色づけされた三角形ポリゴンを中央に描画
- Dear ImGui による情報表示ウィンドウをもち、FPS と解像度情報が表示されている
- ImGuiによる情報表示までを含んだ上で、バックバッファの内容をPNGファイルで保存出来ること
- 起動時引数により、動作モードの設定が可能なこと。引数の仕様は `rules/application-arguments-rule.md` を参照

### 動作のロギング

アプリケーションの実行において、ロギングを有効にすること。

- 参照: `docs/logging-system.md`, スキル: `integrate-error-logging`

### 描画に関する仕様

- 三角形のポリゴン情報はVertexBufferで供給する. `SV_VertexID` を活用しての三角形組み立てをしてはならない
- パイプラインステートオブジェクトの作成においては、使用する全構造体の内容を明示的に初期化すること
- `d3dx12.h` ヘッダファイルを使用してはならない
- DirectX12 のデバッグレイヤーの機能を使い、エラーや警告をチェックすること。
    - 参照: `docs/d3d12-debug-layer.md` , スキル: `configure-d3d12-debug-layer`


### 開発の方針

開発工程をマイルストーンとして細分化し、各マイルストーンを達成してから次に進む。
各マイルストーンは、AIエージェントチームでさらに作業タスク単位に細分化して進め、チームでの検証を行う。
マイルストーンの達成が出来ない場合、ユーザーに問題の報告を行い、指示を仰ぐ。

### 検証方針

本プロジェクトでは、人間による目視確認だけではなく、AI エージェント自身がアプリケーションを実行し、結果を確認できる状態を作る。
そのため、各マイルストーン完了時に次の検証を必須とする。

#### 共通検証項目（全マイルストーン）

| 項目 | 検証方法 | 合格基準 |
|------|----------|----------|
| ビルド成功 | CMake + Visual Studio 2022 | コンパイルエラーなし |
| アプリ起動 | 実行ファイルの実行 | 終了コード = 0 |
| trace.log 存在 | ファイル存在確認 | `bin/trace.log` が存在する |
| trace.log UTF-8 | エンコーディング確認 | UTF-8 で読み込める |
| APP END マーカ | text grep | `=== APP END ===` が存在する |
| FAILED 未存在 | text grep | `FAILED` が trace.log に存在しない |
| タイムアウト未発生 | 実行時間計測 | 10 秒以内に終了（--loop-frame 5 時） |

#### 描画に関する検証項目

PNGによるキャプチャ機能を実装後、以下の項目に対してチェックを行う。

| 項目 | 検証方法 | 合格基準 |
|------|----------|----------|
| キャプチャの開始 | テキスト読み取り | trace.log にキャプチャ開始情報が記録される |
| キャプチャの完了 | テキスト読み取り | trace.log にキャプチャ完了、PNG保存が記録される |
| PNG 存在 | ファイル存在確認 | `capture.png` が存在する |
| 背景色一致 | 画像のVision読み取り | 背景領域の全ピクセルが ClearColor と一致 |
| 三角形存在 | 画像のVision読み取り | 既知の三角形内部ピクセルが背景色と異なる |
| ImGui 描画 | 画像のVision読み取り | 画像内に ImGui ウィンドウが含まれる |
| FPS 表示   | 画像のVision読み取り | 画像内に FPS 値が表示されている |
| 解像度表示 | 画像のVision読み取り | 画像内に 解像度情報が表示されている |
