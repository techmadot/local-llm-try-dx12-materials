# ソースコードのバージョン管理

ソースコードのバージョン管理には git を使用する。
本ファイルでは、バージョン管理すべき対象を記載している。

**バージョン管理するもの**:
- ソースコード(C++, HLSL) 
    - 原則として `(プロジェクトフォルダ)/src` 以下のファイル群
- ビルドなどに必要とする関連ファイル
    - 例: CMakeLists.txt, *.bat
- リソースデータ
    - テクスチャ、画像データなど
- git サブモジュールとして追加されている外部ライブラリ    

**バージョン管理しないもの**:
- 実行体などの成果物
    - ./bin フォルダの内容
    - trace.logなどの確認ファイル
- 中間生成物
    - cmake によって作成される sln, vcxprojなど
    - obj などの中間生成物
- cmake のビルド工程によって取得されるもの
    - 外部ライブラリのソースコード

## コミット時のルール

- 必要なファイルだけをバージョン管理に追加すること
- コミット直前には、必要なファイルがステージングされているかを確認すること
- コミットメッセージは `Conventional Commits` の規約に沿うこと
    - 詳細な説明を書くメッセージ本文には、日本語で記述すること

## 禁止事項

- 必要性を判断せずに、バージョン管理にファイルを追加・ステージングすることを禁止
